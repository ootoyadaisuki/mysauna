# サウナ県ととのい市 — 舞台の架空化

第2章の舞台を、実在の横浜から**架空のサウナ県ととのい市**へ移す（作者決定 2026-08-09）。
ライバル5軒は作者の設定書「**ととのい五名館**」（2026-08-09 受領）が正。この文書はその実装側の台帳。

## なぜ架空にするか

**第1章がすでに架空の町**だから。第1章の舞台に名前は無く、ずっと「この町」で通してある
（杉山・閉まった砕石場・商店街／`js/data.js` の `sauna_sp` の説明文がその象徴）。
実在の街を使っていた第2章のほうが、シリーズの中で浮いていた。

副産物として、**ライバル店のオーナーを自由に出せる**ようになる。
作者方針：**逆転裁判のようなコミカルさ。ただし今までの世界観は壊さない。**
＝コミカルなのは登場人物だけ。地の文と店の描写は真顔で通す（五名館の設定書もその書き方になっている）。

## 唯一の書き方の決まり

**語り手は「サウナ県」を一度も茶化さない。**

- ❌「サウナ県。県名からしてふざけている」
- ⭕「サウナ県ととのい市。人口あたりのサウナの数が、日本一だという」

第1章の地の文のルール（漢数字・落ちは「——」・弱点は客に言わせる）は**そのまま守る。**
一発ギャグの地名は増やさない（冗談は県と市の名前だけ。重ねると真顔で通せなくなる）。

## この章の背骨（作者決定 2026-08-09）

> **一見めちゃくちゃ強く見える各施設にも、夫婦経営の新興サウナが勝てるスキマがある。
> そこを突いていけば、自分の勝ち筋がある。**

だから点数は「強い順に並べる」のではなく、**5軒それぞれに、小さい店だから刺せる穴を1つ置く**。
穴の条件は3つ。

1. **見つけられる**（視察の一枚絵と立ち話で気づける。※「弱点は客に言わせる」は既存の設計）
2. **刺せる**（金の力ではなく、置き方・値付け・気配りで届く）
3. **向こうは直せない**（直すと、その店がその店でなくなる）

3が肝。**強さがそのまま弱さになっている**から、大箱は追いつけない。
