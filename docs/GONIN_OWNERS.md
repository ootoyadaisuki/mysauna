# ととのい五名館オーナー — 台本（S級最終稿）

**ChatGPT壁打ち5往復。辛口再審査（4回目=A → 5回目=S判定）で確定。**
キャラ別評価：神代S／鉄治S／玲華S／澪S-（実装次第でS）／美和子A+（テンポの実装依存）。
審査員の結論：**「ここから足せば落ちる。今後の仕事は強化ではなく、削る勇気と出現頻度の制御」**

作者方針：**逆転裁判のようなコミカルさ。ただし今までの世界観は壊さない。**
＝コミカルなのは**登場人物だけ**。地の文と店の描写は真顔で通す。
地の文ルール（漢数字・落ちは「——」・弱点は客に言わせる・サウナ県を茶化さない）は全場面で守る。

## 共通設計

- 5人は**敵ではない**。「理想だけで店を始めた夫婦が、本当に生き残れるのか」を見ている
- **弱点を本人は絶対に認めない**。弱点は**客の立ち話**が言う
- 各人、**予選前に1回だけ**固有の対抗策を打つ（予告制・タスク#43と連動）
- **クセは一場面に一回まで**（壁打ち指摘。連発すると能力がギャグに落ちる）
- **地の文は人物の行動を評価しない**。
  ❌「美和子はまたインカム芸を始めた」→ ⭕「美和子は返答の途中で右手を耳に当てた」
- 笑いの発生位置が5人で違う（これが被り防止の芯）：

**美和子＝動、澪＝静**を台本全体で固定する：
美和子は常に歩き・振り向き・指示し・文が途中で切れる。澪はほぼ動かず・完全な敬語で最後まで言い切る。
圧の正体も違う——美和子は**決断の速さ**、澪は**沈黙と観察**。

### 吹き出しの演出ルール（S級審査＝40〜60字制約の点検より）

- **「……」だけの吹き出しを出さない**。間は文字でなく**モーションとSE**で作る
  （無言=スプライト停止／気まずさ=顔の向き／判断=小道具モーション／驚き=一歩後退／間=0.5〜1秒）
- 神代は**一吹き出しに数字一つ**。長くすると弱くなる
- 美和子の**インカム芸は初回だけ大技**（3吹き出しに分割）。再訪は
  「三番、補充お願い。——で、今日は何を見に来たの？」まで縮める
- 澪の指摘対象は**画面上に存在するもの**に限る（見えない「棚の裏側」を連発しない。
  タオルが一枚斜め→直しながら「こちらだけ、向きが違いますね」）

### 1人1回の「ダサい瞬間」（有能さと無関係なところで一瞬だけ）

S級のキャラには一回くらい「この人アホだな」が要る。世界観は壊さない。

| 誰 | ダサい瞬間 |
|---|---|
| 神代 | おばちゃん「あんた、サウナ入るの？」神代「週平均二・七回です」「いや、**好きなのか**って聞いたの」——神代、止まる |
| 鉄治 | 最新のQR決済だけ**絶望的にできない** |
| 美和子 | 落とし物ポケットから**自分のロッカーキー**が出てくる |
| 玲華 | 茶の話は完璧なのに、**自販機の缶茶が妙に好き** |
| 澪 | ソファに座る。三秒。クッションの角度が気になる。立つ。直す。また座る——「休んでおります」（**立ったまま**） |

### 最終関係は5様（全員を主人公のファンにしない）

三人目で「この人も最後は認めてくれるんだろうな」と読まれたら負け。

| 誰 | 最終関係 |
|---|---|
| 鉄治 | 完全に認める |

| 澪 | 認める。ただし**最後にも一つだけ直す** |
| 神代 | 敗北を明確に認める（最後の正式な承認者） |

## 1. 神代 蓮司（かみしろ れんじ）— SAUNA GATE 37

**異名＝サウナ業界の合理王。最終戦の相手。**

- **因縁**：主人公が前の仕事で**設備を売った相手**。因縁の芯＝

- **哲学**：「最高のととのいを、誰が担当しても再現できるようにする。それが経営です」
- **クセの使い方**：異常に正確な数字は**一場面に一つ**。
  初対面「初めまして——ではありませんね。四年前の三月。納品は二日遅れました」（発注番号までは言わない）
- **二次動作**：他人の曖昧語を数字に変えさせる（一場面一回）。
  主人公「最近、かなり評判がよくて」／神代「**“かなり”は何％ですか**」
- **スキマ（🌤55）**：本人は「回転率の最適化」と言い張る。
  客の立ち話（**人気とシステム化が生む待ち時間**の軸。松乃湯＝「作る思想がない」と完全分離）：
  「サウナは最高だよ。**ただ、入るのに並んで、出ても並ぶ**。ととのう頃には、**次のアウフグースの列ができてる**」
- **対抗策（1回）**：総点据え置きの配分振り替え。実況「GATE 37、看板部門を強化！——そのぶん、どこかが薄くなった」

  - 最終戦前：「数字は嘘をつかない。**あなたたちの数字は、まだ私に届いていない**」
- **優勝エンドの崩れ（最後の正式な承認者・唯一、発表の後）**：
  **タブレットの画面を消す。**「数字はもう十分です。**お二人の勝ちです**」
  ——神代が初めて、数字を使わずに人を評価する
- **月曜イベントの種**：視察に行くと向こうから席に案内される。「お二人の店の昨日の客数、当ててみせましょうか」

| 3 | 発表の直後 | 玲華 | 茶缶の蓋を開けない。「確かめる必要はありません。優勝は、お二方です」「……私が通うかどうかは、別の話ですが」 |
| 4 | 発表の直後 | 澪 | タオルを一枚だけ直す。「こちら以外は」——でも、少し笑う |

小道具を封印するのは鉄治・玲華・神代の三人だけ。美和子と澪は**クセの意味が変わる**
（五人全員が同じ文法だと「次はこの人のアイテム封印ね」と構造が見える——壁打ち3回目）。

## 5人同士がぶつかる3場面（ボスセレクト画面にしない・S級審査より）

主人公 ↔ 各人の五本線だけだと「ボスセレクト画面」。**主人公がいなくても揉めている**場面を3つだけ入れる。

1. **中間発表**：神代「茶煙楼、個性九十六点。収益性は——」玲華「**聞いていません**」
2. **サウナ協会の会議**（月曜イベント）：美和子「鉄治さん、また値上げしてないでしょ？」
   鉄治「うるせえ」「電気代は？」「**……**」（←ここは吹き出しでなくスプライト停止で）
3. **最終戦の会場**：澪「三分、待たせましたね」神代「二分五十秒です」澪「**長いと申し上げたのです**」

## 5人の関係（主人公がいない所でも街が動いて見える）

- **神代×澪**：元同僚。「サービスも数値化できる」vs「最後の数％は人間にしか作れない」。会うたび静かな論争
- **神代×玲華**：最も仲が悪い。神代は茶煙楼の企画を大規模展開し、玲華は「物語の大量生産」と呼ぶ

## 視察の台詞設計（4段階＋条件反応・壁打ち2回目）

一人につき約12ユニット（初回1＋値踏み3＋対抗策1＋中盤3＋予選後3＋エンド1）。五人で約60本。

| 段階 | いつ | 中身 |
|---|---|---|
| 1. 初回 | 初視察 | **完全固定の名場面**。クセ・思想・小道具を全部見せる。長めでいい |
| 2. 値踏み | 二〜三回目 | **うちの店の実データを参照**する短文。神代「清潔評価、前回比三・二ポイント上昇。改善されていますね」／鉄治「……排水の音、変わったな」／美和子「客は増えたね。でも受付に一人足りない」／玲華「前より、借り物の匂いが減りました」／澪「待ち時間は短くなりました。**音は、まだですね**」 |
| 3. 予選・対抗策 | 予選期間 | 固定イベント1本（七日替わり薬湯・ムーンライトプラン等の予告）＋牽制の短文二〜三本。**まだ褒めすぎない** |
| 4. 予選後〜最終戦 | 終盤 | 態度が**ほんの少し**変わる。突然デレさせない——神代は数字は出すが「無意味」と言わなくなる／鉄治は無言で故障箇所を教えて帰る／美和子は質問を最後まで聞いてからインカムへ戻る／玲華は初めて肯定判定を出す／澪は良かった所を**先に**一つ言う |

- 実装は**シャッフルバッグ**（プールを一周するまで同じ台詞を出さない）。
  処理順＝初回未読 → 固定イベント未読 → **施設状態に対応する特殊台詞** → 現在段階のプール
- ネタが尽きたら無理に喋らせない。鉄治が配管を一度叩いて「今日は問題ねえ」だけ、
  玲華が茶缶を開けて「……今日は、ありません」だけの日があっていい（そのほうが世界として自然）

## 妻 × 五人（壁打ち3回目・濃淡をつける）

五人が立った分、妻が「高額投資に反対する人」だけになる危険がある。
**美和子と澪だけ一段深く。残り三人は経営者として妻を認める。**五人を夫婦カウンセラーにしない。

| 誰 | 妻に対する役割 | 場面の種 |
|---|---|---|
| 神代 | **意思決定** | 妻を「奥さん」と扱わない。「共同経営者でいらっしゃいますね。高額決裁は、どちらが？」妻「二人です」——「……最も時間のかかる方式ですね」（間）「**そして、壊れにくい**」 |
| 鉄治 | **持続可能な働き方** | 春江と妻を重ねすぎない（「春江に似てる」はやらない）。働きすぎの二人に「二人でやってる店で、片方が倒れりゃ戦力半分——じゃねえ。**店が止まる**」コン。「**休める段取りも仕事だ**」 |
| 玲華 | **二人の違い** | 「お二方は、この店をどんな場所にしたいのですか」——夫婦が違う答えを出す。沈黙。茶缶を閉じる。「それでいいのでは。**二人で作る店が、一つの考えしか持たないほうが不自然です**」（意見対立を「悪い状態」だけにしない役） |
| 美和子 | **時間**（一段深く） | 妻「社長なのに、休めるんですか？」——インカム。『社長、食堂レジ——』「そこは任せる」（間）「休みってね、空いた日に取るものじゃないの。**先に空けるの**」「……覚えるの、ちょっと遅かったけどね」——これ以上説明しない。後日、妻が主人公に「今日は店の話、やめない？」と言えば伏線が繋がる |
| 澪 | **二人で過ごす意味**（一段深く） | 妻「ここ、二人で来ても別々にならないように作ってるんですね」——澪「一緒に来た方が、別々の満足だけ持って帰るのは、**少し寂しいでしょう？**」それだけ。離婚の話はしない。後日、妻「澪さん、なんであんな言い方したんだろう」 |

## 初回名場面の順序自由（壁打ち3回目・全員◎）

プレイヤーは視察先を自由に選ぶ。五人の初回はどの順でも成立させる。**システム側の前提が二つ**：

1. **サウナバトルの説明をライバルにさせない**。大会発表は最初の視察より前に
   TVニュース／ゲームUIで済ませる（→五人は全員「大会へ出る新店の夫婦」として主人公を知っている状態から始まる）
2. **主人公の前職（サウナ設備の営業）はゲーム冒頭で一文だけ明かす**
   （神代に120日近く会わないプレイヤーもいるため、他イベントが前職を前提にできるように）

神代は初回から悪の大企業社長風にしない。「お二人がどこまで行くのか、興味があります」くらいで帰す
——何人か会ってから「全員強い。でも神代だけ格が違う」と気づかせる。

## 解決済みの論点

- **名前の衝突**：旧名・松野源蔵は板前の**源さん**（実装済みキャラ）と「源」が被るため、
  **松野鉄治**へ改名（壁打ち2回目で決定。「鉄」はレンチ・設備屋に薄く繋がり、狙いすぎない）

## S維持の掟：全部の仕込みを一周で見せない（壁打ち5回目）

実装でSからAへ落ちる最大の危険＝**名場面を120日で全部強制表示する**こと。
「はい、今はこのキャラの人間味イベントですね」と設計表が透ける。

- **保証するのは物語上必要なものだけ**：春江の2つの仕込み・神代の初対面・優勝エンドの崩れ
- ダサい瞬間・缶茶・ロッカーキーなどは**視察先の選択次第で見逃せてよい**。
  一周目に三人分しか見ない人がいていい。二周目に「え、玲華って缶茶飲むの？」となるほうが豊か
- キャラは「イベント集」ではなく、**プレイヤーの知らないところでも生活している**ように

## S級審査で「守れ」とされた3要素（磨かない・足さない）

1. **神代の初対面**「初めまして——ではありませんね。四年前の三月。納品は二日遅れました」
   ＝五十字で五つの仕事（短い・笑える・怖い・数字キャラ・因縁）。**絶対に残す**
2. **鉄治と春江**の仕込み（写真＋常連の一言）と回収（「春江なら」）
3. **玲華の「設備は真似できる。物語は真似できない」**——個性パラメータをキャラの言葉で理解させる。
   同系統の名言を**増やさない**。玲華の代表台詞はこれ一本
