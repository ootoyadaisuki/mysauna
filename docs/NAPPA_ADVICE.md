# 熱波太郎のアドバイス — 常設30本

第2章の外観図パネルに常駐する熱波太郎が喋る「攻略の基本」。
**進捗に関係なく、いつ出てもおかしくない普遍的な助言**だけをここに置く
（「靴箱がいっぱいだ」のような**その日の状況**を読む助言は別枠＝状況アドバイス）。

## 書くときの決まり

- **1本＝1つのことだけ。** 2つ言うと、どちらも実行されない
- **数字を必ず入れる。**「近づけろ」ではなく「3マス以内」。ゲームの実装値と一致させること
- **口調は熱波太郎。** ぶっきらぼう・断定・「〜だぞ」「〜しろ」。主人公を「あんた」と呼ぶ
- 40字前後。折り返して3行になると読まれない
- **ボタンは1つだけ。** 押した先で、その助言をそのまま実行できる画面へ飛ばす

## 出し方（実装メモ）

- **1日1本、朝に選ぶ。**営業中に差し替えない（読んでいる途中で変わる）
- **直近10本は出さない**（`G.ch2.advSeen` に id を積む）。30本あるので3週間は同じ話をしない
- **状況アドバイスが立っていれば、そちらを優先。**この30本は「今日は言うことがない日」の受け皿
- `req` を持つ本は、その条件を満たすまで出さない（無い物の話をしても仕方がない）
