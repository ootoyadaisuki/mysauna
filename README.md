# 俺のサウナ ― 夕凪湯 再建記 ―

倒れた親父の古い銭湯「夕凪湯」を引き継ぎ、自分好みのサウナ施設へ再建していく
カイロソフト風・見下ろしドット絵の経営シミュレーションゲーム（ブラウザ版プロトタイプ）。

## 遊び方

サーバーを立ててブラウザで開く（スマホ縦持ち推奨）:

```
cd ~/Dev/oreno-sauna
python3 -m http.server 8931
# → http://localhost:8931 を開く
```

ビルド不要・依存ライブラリなし（素のHTML/CSS/JS + Canvas）。

## ゲームの流れ

1. 導入ストーリー（残業→親父が倒れる→ボロボロの夕凪湯へ）
2. 屋号を決める（のれん・看板に反映）
3. 準備フェーズ（0時〜9時）: 設備の購入・配置・移動・売却、データ確認、広告、融資
4. 営業フェーズ（9時〜24時）: 客が来店→番台で支払い→脱衣→**ガラス引き戸**をくぐって浴室へ→洗い場→風呂・サウナ→帰宅。営業中も下部の設備カタログから買い足せるし、**設備の移動・売却もできる**（使用中の客はどいてもらう＝満足度は下がる）
5. 一日の終わりに営業レポート（**本日の収支を最上部に大きく表示**／売上・経費・満足度・評判・お客の声）

## 主なシステム

- **お金**: 貯金**500万**でスタート、借金はなし（親父は借金嫌い）。遠赤サウナ(80万)＋水風呂(40万)＋ロッカー・カラン・イスを揃えても200万以上残る＝1週目から「箱を整えてから開ける」余裕がある。拡張資金は利益か、信用金庫の借入で。ただし**初めて借りると親父が電話で小言**を言ってくる（手動の借入でも、資金ショートによる自動借入でも初回に発動）。守りの親父 vs 攻めの主人公
  - **信用金庫は500万が限度**（50万単位・利息0.5%/日）。街の小さな銭湯には、それ以上は貸してくれない（貯金500万＋融資500万＝1,000万が正攻法で動かせる上限）
  - **ヤミ金「灰田金融」**: 信用金庫が限度いっぱいの時だけ手が出せる最後の手段（30万単位・**利息5%/日**）。**毎日、開店直後に灰田が集金に来る**（元金の10%）。払えなければ**バットを持った若い衆が上がってきて、設備を叩き壊して持って行く**。完済すれば二度と来ない
    - 取り立ての画面には「払う（本日ぶん）」「**完済する（元金＋今日の利息）**」「待ってくれ…」の3択がある。今日ぶんだけ払い続けると利息5%/日で元金が減らずいつまでも通ってくるので、**金があるならその場で縁を切れる**。融資画面の【🩸 完済する】も同じ額（`yamiPayoff`）
  - **設備の売却額は購入額の10%**。買い直すと丸損＝置き場所と品揃えは、よく考えて決めろということ
- **運営メニュー（⚙運営）**: 経営の要。集客と経費のバランスを自分で決める
  - 入浴料: ¥600/700/800 ＋ **「自由」**（スライダーで¥500〜**¥1,000**。説明欄に「¥500〜¥1,000まで選べる（今の目安：¥○○）」＝いまの設備で納得される額を出す）。安いと集客↑・高いと単価↑。**設備が充実するほど高くても納得される**（納得の目安額をメニューに表示）。ただし小さな銭湯なので、どこまで尽くしても**上限は¥1,000**
  - サウナ料: ¥300/400/500 ＋ **「自由」**（¥200〜¥700）。入浴料への上乗せで、サウナ目当ての客だけが払う。**サウナを設置して初めて設定できる**（未設置なら🔒）
  - ドライヤー: **無料 / 1回¥20**（脱衣所に**洗面所**を設置すると設定できる。ドライヤーは洗面所に備え付けで、単独では買えない）
  - 化粧水・乳液: **無料 / ¥50 / ¥100**（同じく**洗面所**を設置すると設定できる。高いほど使う客が減る）
  - タオル: なし / 無料貸出（集客↑）/ 有料（売上↑・集客↓、価格も選択）。**置くだけで経費¥1,000/日**、無料貸出はさらに客数ぶんの洗濯代
  - **手ぶらセット**: タオル＋シャンプー＋ボディソープのバンドル（**¥300/400/500**）。¥700は「その金でもう一回入れる」額なので廃した。手ぶらで来た客が買う。導入中は無料設置を選べず、タオル無料貸出だと誰も買わない
  - シャンプー・ボディソープ: なし / **無料設置**（集客↑・満足度↑・ポンプ代¥1,000/日）/ **販売**（¥50〜¥200で個別に値付け）。どちらも**使われた本数×¥50を自動で仕入れる**。高く付けると買われず、手ぶら客の不満になる
  - サウナマット / 垢すりタオル: ONにすると**浴室内の置き場所を自分で選んで設置**する（OFFで撤去）。経費はどちらも**¥500/日**
  - スタッフ: アルバイトを最大3人まで雇用（日給¥9,000）。できるのは**代金の受け取りと掃除だけ**（修理は業者の仕事）
- **設備カタログは41種**（全国の銭湯の定番設備をリサーチして反映）。タブは 風呂／サウナ／水風呂／洗い場／休憩／**脱衣所**の6つ（**「その他」タブは廃止**＝迷子になる設備を作らず、必ずどれかのタブに入れる。ロッカー・扇風機・観葉植物は【脱衣所】タブ、冷水機は【休憩】タブ）
  - 風呂: 古い浴槽・ぬる湯・あつ湯・**季節の替わり湯（ゆず/菖蒲）**・**電気風呂**・**ジェットバス**・檜風呂・**高濃度炭酸泉**・**寝湯**・**露天の岩風呂**
  - サウナ: 遠赤・**ミスト（60℃固定）**・大型・**塩（55℃固定）**・フィンランド式（ミストと塩は“別ジャンル”＝熱さの好みで評価されず、室温も変えられない）
  - 水風呂: 水風呂（15℃）・**シングル（8℃・チラー／評判45・¥800,000）**・地下水かけ流し（13℃／評判55）。**尖った8℃が先に解放され、万人向けの13℃が後**。シングルは安く買えるが電気代が重い（¥4,000/日）
  - 洗い場: 古いカラン・新しいカラン・**立ちシャワー** ／ 休憩: ベンチ・ととのいイス・リクライニング・**インフィニティチェア**
  - **脱衣所（脱衣所にしか置けない）**: **ロッカー／洗面所（2マス）／体重計／テレビ／昭和アイドルのポスター／将棋台／マッサージチェア／牛乳の自販機／ドリンクの自販機／扇風機／観葉植物**
    - **洗面所**＝鏡と洗面台。**ドライヤーと化粧水・乳液はこの上に置かれる**＝それぞれに1マス使わせない（かつては別々の設備だったのをやめた）。料金の設定は運営メニュー
    - **扇風機・観葉植物は脱衣所専用**。扇風機は**脱衣所の床のみ**（壁には掛けられない）
  - 【休憩】タブ: ベンチ類に加えて**冷水機**（冷水機だけは**浴室にも脱衣所にも置ける**）
  - **左右の壁は「内側の壁」**＝掛けられる面として扱う。**昭和アイドルのポスターとテレビ**は床だけでなく**左右の壁（一番外の列）にも設置できる**。配置中は壁の列も緑／赤で塗り分けられ、確認バーに「左右の壁にも掛けられる」と出る。壁に掛けても脱衣所の縛りはそのまま（どちらも脱衣所側の壁）
  - **置くだけで効く設備**（洗面所・体重計・テレビ・ポスター・将棋台・冷水機・扇風機…）は、客のタイプによって刺さるものが違う。**爺さんはポスター・将棋台・扇風機**、**若い層はテレビ・洗面所**を喜ぶ。サウナがあるのに**冷水機**が無いと、いいサウナでも満足しきれない
- **湯温・湯種**: **温度を設定できるのはドライサウナだけ**（遠赤・大型・フィンランド式＝設備パネルの±で60〜120℃を1℃刻み）。**浴槽・水風呂・ミストサウナ・塩サウナは設備ごとに温度が固定**で、パネルには温度と帯を出すが±ボタンは付かない。
  - **浴槽**（湯温は固定）: **ぬる湯38**／高濃度炭酸泉38／古い浴槽39／寝湯40／電気風呂41／ジェットバス41／季節の替わり湯42／露天の岩風呂42／檜風呂43／**あつ湯44**。客の好みに応える手は「湯温をいじる」ではなく**「別の湯船をもう1種類買う」**だけ
  - **水風呂**: **15℃（水風呂）／8℃（シングル）／13℃（地下水かけ流し）の三種**で、一桁℃を出せるのは**【シングルの水風呂】(チラー)だけ**（安い水風呂を冷やしてシングルの代わりにする、ができないようにしてある）。解放は15→8→13の順
  - **ミスト60℃・塩55℃も固定**＝“別ジャンル”のサウナで、そもそも熱さの好みで評価されない（誰が入ってもそこそこ気持ちいい）
  - 浴槽・水風呂は温度帯で水面が5種（超あつ湯/あつ湯/ぬる湯/水風呂/キンキン水風呂）に変化、サウナは室温60〜120℃で4帯（**低温/中温/高温/灼熱**）＝室温が高いほどヒーターが赤く光り湯気が濃くなる。**マップの札はサウナだけ数字ではなく言葉**（「110℃」ではなく「**灼熱**」）＝熱さが一目で伝わる。正確な室温は設備をタップすれば読める。ミスト60℃・塩55℃はこの帯で「**低温**」と出る＝“低温のサウナ”であることが札の時点で分かる。客の好みに合うと満足度が上がる。サウナー青年はキンキン水風呂＆灼熱サウナ、おばちゃんはぬるめを好む。**じいさんだけは湯温の好みに個人差**があり（`furoVar`＝±5℃／37〜47℃）、同じ「常連のじいさん」でもあつ湯派とぬる湯で長湯する派が混ざる＝**ぬる湯(38℃)を入れると必ず何人かが居着く**
  - **温度と光熱費**: ドライサウナを既定室温（90℃など各設備の初期値）より高く設定すると、1℃につき¥50/日ずつ光熱費が増える。既定より下げても割引はなく、既定額（＝下限）のまま。設備パネルに現在の上乗せ額を表示し、日報の光熱費にも「うち温度上乗せ」を明記。温度が固定の設備では上乗せは発生しない
- **日報に設備投資を出す**: 設備を買った日は、「本日の収支」（営業利益）の**すぐ下に「設備投資をふくめた手残り」**が並ぶ。経費の下には**設備投資の行**（購入／移動／売却の内訳つき）と**所持金 ¥A → ¥B** の行
  - 設備を買うのは経費ではなく買い物なので営業の収支には入らないが、それだけを見せると**「毎日ちゃんと黒字なのに、なぜか金が増えない」**という見え方になる。緑の「+¥13,850」と赤の「-¥1,526,150」を並べて出すのが正直な表示
  - 集計は `G.invBuy` / `G.invMove` / `G.invSell`。**締めは `afterReport()`**＝「日報を閉じてから、次の日報まで」。設備を買うのは主に準備中なので、この区切りだと**「明日のために使った金」が明日の日報に出る**
- **新規客と常連客**: 日報の来店客数に「新規 22人・常連 34人」、その下に「常連の数 152人（+2人が行きつけに／-1人が足を遠のかせた）」
  - `G.regulars` ＝夕凪湯を**行きつけにしている人数**。満足度62以上で帰った新規の35%が常連になり、満足度42未満で帰った常連は離れる（`CONF.regular*`）。常連は3日に1回のペースで顔を出す想定で、その日の来店に占める常連の割合は**開店時に固定**する（今日はじめて常連になった人が、その日のうちにもう一度来ないように）
  - **いまは表示だけで、1日の来店数そのものには効かせていない**（客数の式は従来どおり）。広告→新規→常連の循環を数字として先に回してあり、集客に効かせるかは作者の判断待ち
  - 実測（評判45の店）：常連の割合が 1日目0% → 10日目30% → 35日目43%。**休日は来店見込みが増えるぶん新規の比率が上がる**（＝休日に新しい顔が来る）という挙動が勝手に出た
- **日報の「仕入れ」**: タオル・アメニティ・**牛乳**の仕入れは1行にまとめ、右側に「タオル -¥○／アメニティ -¥○／牛乳 -¥○」と**項目と金額だけ**を並べる
  - **牛乳・ドリンクは1本¥50で仕入れる**（`CONF.milkUnitCost`）＝売れた本数ぶんだけ自動で。売価¥130なので1本¥80のもうけ
- **光熱費と水道代は別建て**: 日々の経費は「光熱費」（湯を沸かす・室温を上げるガス電気＝サウナ・風呂・水風呂・自販機）と「水道代」の2本立て。**水道代はカラン・風呂・水風呂の大きさ（占有マス数×¥350/日）で決まる**＝大きい湯船ほど水をたくさん使う。カランは水道代のみ（光熱費は取らない）で、状態が悪化すると壊れて修理が終わるまで使えなくなるだけ。設備パネルと日報の両方に水道代を表示
- **光熱費・水道代は変動制**（`dailyUtil` / `dailyWater`）＝**「基本（設備の待機ぶん）＋従量（客1人あたり）」の二階建て**。設備の`run`・水道代として表示される額は“満員で回した時”の額で、毎日必ず出ていくのは**その20%**（`CONF.utilStandby`）だけ。残りは**客1人あたり光熱費¥60＋水道代¥40**（`utilPerGuest`／`waterPerGuest`）に移してある
  - **売上比例ではなく客数比例**にしてあるのは、入浴料を上げても使う湯と水の量は変わらないから（値上げが自動的に増税にならない）
  - 日報には「光熱費 -¥15,600／基本 ¥11,460＋客69人 ¥4,140」と**内訳を出す**＝客が増えて経費が伸びた理由が読める。設備パネルの表示も「置いているだけでかかる分」＝待機ぶんに変えてある
  - 固定制のままだと**設備の数だけで決まって客が何人来ても1円も動かず**、売上比が 序盤41.5%／設備を絞った店23.6%／完成した店47.0% とばらばらだった。変動制にして **27.6%／18.8%／20.4%** に収束（序盤だけ高いのは基本料金¥4,500が固定で乗るため＝小さい店ほど固定費が重い、は意図どおり）
- **「1種類だけでは全員を満たせない」**: 客は自分の好みに**いちばん近い一台**を選んで入る（`equipFit`）。90℃派と110℃派、あつ湯派とぬる湯派、キンキン派とぬるめ派がいるので、**サウナも水風呂も浴槽も2つ以上置かないと必ず誰かが不満**を漏らす。
  - **風呂は「種類」で応える**（湯温が固定なので、温度をいじって取り繕えない）。1種類しかないと客が「もっとお風呂の種類がほしいな」「お風呂は1種類しかないのか…」とこぼし、種類はあっても**全部あつ湯／全部ぬる湯**なら足りない側を欲しがる。充実度も**種類の数**で加算（`furoKinds`＝2種類で+3、3種類で+6、4種類以上で+9）
  - **水風呂**も温度を弄れないので、**冷たい槽（13℃か8℃）＋もう一段**の組み合わせで応える（サウナー青年は8℃のシングル一択、サラリーマンも8℃寄り、OLさん・金髪の兄ちゃん・親分は13℃がいちばん合う。じいさん・おばちゃんは15℃でも13℃でも同じ評価）
  - **サウナだけ**は室温を上げ下げして好みに寄せられる（ただし1室では90℃派と110℃派の両方は満たせない）。品揃えは【📊 データ】の「湯の品揃え」で**風呂◯種類 ◎△／サウナ ◎△／水風呂 ◎△**として確認できる
- **休憩設備**: 木のベンチ／ととのいイス／リクライニングチェア／インフィニティチェアの4種。快適さでととのい満足度が変わる（マット系のととのいスペースは第2章＝新店で解放予定）
- **間取り**: 浴室（上）と脱衣所（下）は間仕切り壁で仕切られ、**行き来できるのは中央のガラス引き戸だけ**。引き戸の前後2マスは設備で塞げず、間仕切りをまたぐ配置もできない
- **収容人数**: 浴槽・サウナ・水風呂・カランの定員は「占有面積×1人」（2x2の浴槽＝4人、3x2の大型サウナ＝6人、2x1の水風呂＝2人）。カタログと設備選択パネルに常時表示
- **1日の来店数**: `3 + 評判×0.7 + サウナ補正 + 料金・サービス補正` を **1.3倍**し、さらに**曜日の倍率**を掛けて、上限120人・下限3人（`CONF.guestMul` / `CONF.guestMax`）
- **曜日**: **1日目＝月曜**で、土日が休日。**平日の客数は休日の70%**（`CONF.weekdayGuestRate`）。倍率は**週の平均がちょうど1.0になるよう正規化**して掛けるので（休日1.27倍・平日0.89倍）、曜日を入れても**週あたりの客足の総量は変わらず、日ごとの濃淡だけがつく**
  - トップバー「15日目（月）」・日報の見出し・データ画面の「曜日の客足」に表示。**日報の末尾に翌日の予告**（「📅 明日は6日目・土曜日。休日は客足が伸びる」）を出す＝**広告をどの日に打つか選べる**ようにするため
  - 狙いの70%が出るのは店に余力がある間だけで、**満員に近い店では圧縮される**（実測：序盤の店69%／設備を絞った店75%／完成した店92%）。土曜でも入れる人数には上限があるので、これは正しい挙動
- **もうけ**: 夕凪湯は**家賃もローンもゼロ**（親父の建物をそのまま継いだ）うえ、**主人公の人件費も一円も乗っていない**ので、利益率は高めに出るのが正しい。ここで言う「利益」は会社の営業利益ではなく、**主人公の取り分（個人事業主の所得）**。雇ったスタッフの給料は経費に出るが、自分の働きぶんだけは経費にならず利益に化ける、という個人商売そのままの帳簿になっている。日によって修理費が跳ねるので**15〜30日ならし**で見る。実測：

- **掃除の見える化**: 主人公・スタッフは掃除中にモップを動かす。何をしているか一目でわかる。汚れは**近い順に、実際にたどり着けるもの**から片づける（設備で囲まれて到達できない汚れがあっても、他の汚れの掃除は止まらない）
- **「たどり着けない」の警告**: 設備で通路を塞ぐと、困っている客・主人公・スタッフの頭上に**⚠付きの濃い赤の吹き出し**が出る（「サウナにたどり着けない」「番台にたどり着けない」「汚れの所まで行けない…」）。営業ログにも1日1回出る。運営メニューで直せる不満（赤枠＋「！」）とは別の印＝**これは配置を直すしかない問題**。1人につき6秒に1回まで
- **“飾り”を作れないようにしてある**: 置いた結果どれか1台でも道から切り離されるなら、**その置き方は成立しない**（赤いマス＋確認バーに「⚠ 利用不可になるアイテムがあります（新しいロッカー）」）。**後から塞ぐ置き方も同じ判定で弾かれる**＝隅からロッカーを並べていって、最後の1個が手前の列を殺す、という事故が起きない
  - **巻き添えになる設備は、その場で光って教える**。配置中、使えなくなる設備を**赤い斜線でハッチし、⚠を重ねて点滅**させる（`drawLostMarks`）＝文章を読まなくても「どれが死ぬのか」が見て分かる
  - ロッカーと洗い場の「同じ種類のどれか1台に届いていればいい」という例外は**廃止**した（奥の列＝誰にも使われない飾りを作れてしまうため）。壁ぎわに1列並べるのは今まで通りできる
  - 判定は**「この置き方のせいで新しく切り離される設備」だけ**を見る。古いセーブに既に飾りが残っていると、全部数えたら盤面のどこにも何も置けなくなる（＝詰み）ため
  - それでも古いセーブには飾りが残るので、**マップ上で暗く落として⚠を重ね、タップすると「通路につながっていません」**と理由が読める。飾りは`usable()`が偽＝客の候補から外れ、`facilityScore()`にも数えない（＝本当に何の効果もない）。判定は`refreshDead()`で、設備を買う／動かす／売る／開店する／セーブを読む時に洗い直す
  - 実測：昔のルールで作った飾りのカラン2台は、客31人・丸1日を通して**利用回数0回**（隣の生きた2台は10回ずつ）。充実度も 20.0 → 12.3 に落ちる＝「通路に面していないカランを並べるだけで評判が上がる」抜け道も塞がった
- **ロッカー容量**: ロッカー1台につき6人まで受入
- **設備の劣化**: 使うほど傷むうえに、**1営業日ごとに必ずヘタっていく**。各設備の下辺に**耐久度バーを常時表示**（緑→黄→赤）。傷みの速さは種類ごとに違い、**ロッカーは15日に一度は壊れる**（カラン→湯船・サウナの順に長持ち）。全体の保ちは`CONF.durability`（＝1.5）で調整でき、日々の劣化も使用による摩耗もこの値で割る。古い設備はさらに1.4倍の速さでヘタる。状態が0になると故障し、直るまで使えない
- **修理**（壊れたら自動で来る／自分から呼ぶこともできる）:
  - 主人公もアルバイトも、できるのは**代金の受け取りと掃除だけ**
  - 耐久度が0になると勝手に壊れ、**勝手に修理業者がやって来る**。ヘルメット姿の業者が入口から歩いて来て、トンカチでガンガン叩いて直し（100%／古い設備は75%）、**直し終わった瞬間に頭の上へ修理費がポーンと出て、その場で財布から引かれる**（田所が仲間なら20%引き）
  - **【🔧 修理】ボタン**（設備パネル）＝壊れる前に自分から呼べる。代金は**減った耐久のぶんだけ**（`fixFee`）で、基準は「壊れるまで待った場合の平均額」（不調85%・大規模15%）＝**耐久1%あたりの単価はいつ直しても同じ**。早く直しても損はしないし、得もしない。得られるのは金ではなく「**営業中に止まらない**」こと
  - **準備中（営業時間外）でも来てくれる**のは自分で呼んだときだけ＝夜のうちに直せば客に迷惑をかけない。準備中に払ったぶんは日報の**「設備の修理」**（設備投資の行）に、営業中に払ったぶんは**「修理業者への支払い」**（経費の行）に載る
  - **業者は1台直すたびに帰らない**。頼まれたぶん（作業中に別の設備で【🔧 修理】を押すと「ついでに」渡せる）を先に、次に壊れているものを、**いま立っている場所から近い順**に片づけてから引き上げる
  - **故障には2つの規模がある**（壊れた瞬間に決まり、日報・ログ・設備パネルに明記される）
    - **不調（85%）＝購入額の1.5%**（最低¥3,000／古い設備¥5,000）。パッキン・部品交換・詰まりの類いで、ふだんはこっち
    - **大規模修理（15%）＝購入額の7%**（最低¥7,000／古い設備¥14,000）。数年に一度のオーバーホールで、¥2,400,000のフィンランド式サウナなら**¥168,000**。ヤクザに叩き壊されたぶんは必ずこちら
    - 1回の額は現実の比率どおり（¥2,400,000の設備に¥168,000）。**現実的でなかったのは頻度のほう**で、全部の故障を7%にしていた頃は年間で購入額の70〜105%を修理に払っていた
  - 同時に来るのは1人まで。客が使う設備から先に直す。**修理代が払えない日は業者が来てくれない**＝壊れたまま営業することになる
  - 若い衆が暴れている最中は業者を呼ばない（叩き壊された設備も、収まってから直しに来る）
- **行列と不満**: 設備が満員・故障で使えない客は、その設備の前まで歩いて**並んで待ち**、定期的に不満をこぼす（満員＝「まだ空かないのか…」/ 故障＝「壊れてるじゃないか」）。待つほど満足度が下がり、限界を超えると諦めて次へ
- **すべての設備に、必ず手前の立てるマスが要る**: ロッカー・洗い場も含めて例外なし。壁ぎわに1列に並べるのはできるが、**その手前をさらに埋めて「奥の列」を作ることはできない**（誰にも使われない飾りになるため）。冷水機・扇風機・洗面所も「実際に歩いて行って使う」設備なので道が要る（`PAS_USE_IDS`）。ポスター・観葉植物・テレビ・体重計・将棋台は隅に押し込んでよい
- **主人公**: 番台での受付と、汚れの掃除を自動でこなして施設内を走り回る。**番台についている間は、台の向こう側から頭だけ出して座っている絵**になる（`atBandaiPost`）
- **客の動線**: 来る客は**入口の右手から歩いてきて**、帰る客は**左手へ抜けていく**＝出入りがぶつからない。番台前に入りきらない客の行列も右へ伸びるので、「捌けていない列」と「帰り道」が交差しない
- **湯船の見せ場**（`drawFuroFx`／画像は持たず全部その場で描く）:
  - **ジェットバス**＝左右の噴き出し口から泡を巻き込んだ水流が中央へ伸びる
  - **高濃度炭酸泉**＝細かい泡が底から湯面へ立ちのぼり続ける（シュワシュワ）
  - **電気風呂**＝左右の電極板と、ときどき走る黄色いビリビリ（出しっぱなしにはしない）
- **効果音**（`js/sfx.js`／**音のファイルは1つも持たず、その場で合成する**）: ボタンを押すと**ピッ**（画面下のカタログで設備を選んだ時・マップで設置場所を選んだ時も鳴る）、セリフが出ている間は**ピピピピ**、売上は**チャリーン**、出費は**バコーン**、営業結果（日報）が開くと**ガッチャーン**（レジ）、**黒塗りのベンツが走っているあいだは「ブオーン」**（停まると切れる＝エンジンが止まる間が“降りてくる”前触れになる）。☰メニューの【🔊 効果音】で切り替えられ、設定はブラウザに残る（`orenoSauna_sfx`）
- **BGM**（同じく`js/sfx.js`／**曲のファイルも持たない**）: 譜面は8分音符ごとに1マスの文字列（`C5`＝鳴らす／`-`＝のばす／`.`＝休み）で `SONGS` に書いてあり、**書き換えれば曲が変わる**（コードは触らなくていい）。☰メニューの【🎵 BGM】で**効果音とは別に**切り替えられる（`orenoSauna_bgm`）。※**曲はすべて叩き台**
  - **営業中「夕凪湯のうた」**（96拍・16小節・約40秒／**ヨナ抜き長音階＝ドレミソラ**）＝昭和の歌謡曲や童謡の音階。暖簾を出すと鳴り出す
  - **準備中（夜）**（72拍・8小節・約27秒）＝昼と同じ音階のまま速さと編成だけ落とす。太鼓なし・やわらかい音・音量控えめ＝**同じ店の、時間だけが変わった音**
  - **ストーリー場面**（66拍・8小節・約29秒／**都節＝ラ・シ♭・レ・ミ・ファ**）＝人が話している下で鳴るので、いちばん薄く小さく。昼の曲と音階そのものを変えてあるので、場面が変わったと耳で分かる
  - **エンディング**（108拍・16小節・約36秒）＝営業中と同じ音階のまま速く・高く・厚く。「同じ店の同じ歌が、ここまで来た」という作り
  - **みかじめ料の来訪と、ヤミ金の取り立てのあいだは無音**。曲を止めて、ベンツのエンジン音と静けさだけを残す（決着して営業が再開すると、また営業中の曲に戻る）
  - 日報も静か＝レジの**ガッチャーン**が立つ
- **配置エリアの色分け**: 設備を置く／動かすとき、**置けるマスは緑・置けないマスは赤（斜線）**に塗り分けて表示。浴室限定・脱衣所限定の設備は、その部屋そのものが緑の枠で囲まれる
  - 緑＝「**このマスをタップすれば置ける**」の意味。2×2の遠赤サウナのような大きい設備は、タップしたマスを必ず含む置き方をタップ位置に近い順に総当たりし、置ける置き方があれば**自動でずらして**置く（古い浴槽の左隣、部屋の右端・下端をタップしても、はみ出さない位置に収まる）
- **【📊 データ】**: 準備中・営業中どちらからも開ける計器盤。営業データ（資金・借入・ヤミ金残債・直近5日の平均収支と黒字日数・入浴料と納得される額）／客の評価（評判・充実度・ととのい率・受入人数・**湯の品揃え**・客が欲しがっている物）／設備の状態（傷んでいる順）／人との関係（常連との絆・親父・**すでに会った相手だけ**）／いま受けている注文／投票対決の残り日数と見込み票。※**先の展開や「残りいくつ」は出さない**（下記のエンディング方針どおり）
- **営業のテンポ**: 運営メニューとデータは**営業中も開ける**（**運営・データ・一時停止/再開・速度**を横一列に等幅で並べる。上の行に客数・売上・場内人数）。速度は1/2/3で切替。速度1は約2.5マス/秒＝セリフを読みながら追える速さ。⏸で一時停止（吹き出しをじっくり読める）
- **営業中の設備メニュー**: 営業中でも設備をタップすると、**準備中とまったく同じ内容**（状態・光熱費・説明・湯温/室温の表示とサウナの室温調整・移動・売却）が開く。営業中に移動・売却すると、使っていた客はどいてもらうことになり満足度が下がる
- **新着マーク**: 評判で新しい設備が解放されると、そのカテゴリのタブに🔴が付く。自分でタブを開くと消える（`G.seenEq`に記録・セーブ対象）
- **ストーリーイベント**: 初日夜に母の電話、評判30で親父が黙って入りに来る
- **セーブ**: localStorageに自動保存。タイトルの「つづきから」で再開
- **【☰ メニュー】**: 上のバーの**右上**。準備中でも営業中でもいつでも開ける。中身は**💾 いまの状態を保存**／**🏠 トップ画面へもどる**（「保存してもどる／保存せずもどる／やめる」の確認つき）／とじる。営業中は「保存すると、この日は準備中からやり直しになる」と断り書きが出る（セーブはその日の頭までしか持たないため）
  - **ウェブサイトなどの外部リンク**は`js/data.js`の`MENU_LINKS`に`{ label:'🌐 公式サイト', url:'…' }`を1行足すだけでボタンが増える（別のタブで開く。空なら何も出ない）
- **PWA対応**: `manifest.webmanifest` ＋ `service-worker.js`（ネットワーク優先）。スマホの「ホーム画面に追加」でアプリのように起動でき、オフラインでも遊べる

> **想定プレイ時間**: 第1章は**100日ほどでクリアできる**傾き。評判は上へ行くほど伸びにくく、詰まるのは時間ではなく**金**（毎日の劣化と修理費・売却は購入額の10%・信用金庫は500万まで）と、田所／黒田の**注文をこなす手間**。※数値はすべて叩き台
